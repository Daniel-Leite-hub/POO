# 💻 Repositório de Programação Orientada a Objetos (POO) & TypeScript

Este repositório reúne resoluções de exercícios, projetos práticos e anotações teóricas desenvolvidos ao longo dos meus estudos em **Programação Orientada a Objetos (POO)** e **TypeScript**.

## 📌 Conteúdo do Repositório

- **Fundamentos de TypeScript:** Tipagem estática, inferência de tipos, compilação (`tsc`), depuração (`sourceMap`) e configurações do `tsconfig.json`.
- **Programação Orientada a Objetos (POO):**
  - Classes, Atributos, Métodos e Instanciação
  - Encapsulamento, Abstração, Herança e Polimorfismo
  - Relações entre Objetos (Associação, Agregação e Composição)
- **Boas Práticas & Arquitetura:** Aplicação gradual de princípios SOLID e padronização de código.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** TypeScript / JavaScript (Node.js)
- **Ferramentas:** VS Code, Git, `tsc` (TypeScript Compiler)
